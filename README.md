# Schulte Table

A mobile-friendly Schulte Table game built with Python and Kivy.

The game helps train focus, visual perception, reaction speed, and attention. Players tap numbers in the correct order as fast as possible.

## Features

- Classic Schulte Table mode
- Countdown mode
- Reverse mode
- Lives mode
- Level system
- Local progress saving
- Animated UI
- Mobile-friendly layout
- Built with a modular structure following SOLID principles
